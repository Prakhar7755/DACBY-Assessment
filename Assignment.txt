Objective 
Build a mini full-stack web application using the MERN stack (MongoDB, Express, React, Node.js) that demonstrates your ability to design, develop, and integrate both frontend and backend systems. 

  Assignment Overview 

1. Web Scraper 
Develop a scraper to fetch data from: 
https://news.ycombinator.com 
Requirements: 
Scrape the top 10 stories 
Extract and store the following fields: 
Title 
URL 
Points 
Author 
Posted Time (postedAt) 
Save the data in MongoDB 

Scraper should: 
Run automatically on server start 
Be triggerable via API: POST /api/scrape 

2.Backend (Node.js + Express) 
 Authentication (JWT-based): 
POST /api/auth/register → Register a user 
POST /api/auth/login → Login user 

  
Story APIs: 
GET /api/stories → Fetch all stories (sorted by points in descending order) 
GET /api/stories/:id → Fetch a single story 
POST /api/stories/:id/bookmark → Toggle bookmark (Authentication required) 

 3. Frontend (React) 

  Features to implement: 
Display list of stories with: 
Title 
Points 
Author 
Posted time 
User authentication: 
Login & Register pages 
Bookmark functionality: 
Toggle bookmark for stories 
Persist bookmark via backend API 
Protected Bookmarks Page 
Manage authentication state using React Context API 

Technical Guidelines 
Use .env file for all environment variables and secrets 
Follow a clean and scalable folder structure:

controllers/ 
middleware/ 
Write clean, readable, and maintainable code 

Avoid: 
Hardcoded values
